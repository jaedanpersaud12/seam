Everything a diff tool should do, nothing it shouldn't.

It works the way classic visual diff tools do, with a modern look and an engine that keeps up with big files and bigger folders.

Side by side, to the character

Changed lines are tinted and the exact words and characters that changed are highlighted. Ribbons show where every change lands.

Patience diff by default

Moved functions and closing braces line up the way a person would expect. Switch to Myers or Histogram with one click.

Whole folders

Walks both trees in parallel and hashes with BLAKE3. Files are marked identical, different, one-sided, or equivalent under your rules.

Edit and merge across

Both panes are editors. Copy a change to the other side with an arrow or ⌘], then save each side with its original encoding.

Ignore what doesn't matter

Trailing whitespace, amounts of whitespace, all whitespace, case and line endings. Folder results follow the same rules.

Paste to compare

No files? Open a text comparison and paste two snippets. Handy for configs, logs and API responses.

Lives in your terminal, too.

Install the seam command from the app menu. Seam offers to register itself as git's difftool; --wait keeps git paused until you close the comparison.

$ seam old.json new.json
$ seam ./v1 ./v2 # folders work too
$ git config --global diff.tool seam
$ git difftool HEAD~1
